1. SEO Kritis

Meta title & description tidak dioptimasi

Halaman utama menggunakan judul default WordPress tanpa keyword target. Meta description kosong di sebagian besar halaman.

⚠ Dampak tinggi · Perbaiki segera

Tidak ada sitemap XML & robots.txt

Search engine kesulitan mengindeks halaman portofolio dan proyek. Potensi kehilangan traffic organik signifikan.

⚠ Dampak tinggi · Perbaiki segera

Konten teks sangat minim

Halaman portofolio hanya berisi gambar tanpa teks deskriptif. Google tidak bisa membaca gambar — kata kunci tidak terindeks.

● Dampak sedang · Direkomendasikan

Alt text gambar kosong

Seluruh gambar portofolio tidak memiliki alt text. Ini merugikan SEO gambar dan aksesibilitas pengguna.

● Dampak sedang · Direkomendasikan

2. Performa & Kecepatan Perlu Perhatian

Gambar tidak dikompresi (ukuran besar)

File gambar portofolio berukuran 2–5 MB per gambar. Estimasi load time halaman: 8–12 detik. Standar yang baik adalah di bawah 3 detik.

⚠ Dampak tinggi · Perbaiki segera

Tidak ada caching browser

Setiap kunjungan mengunduh ulang semua aset. Plugin caching seperti WP Rocket atau LiteSpeed Cache dapat memangkas waktu muat hingga 60%.

● Dampak sedang · Direkomendasikan

HTTPS sudah aktif ✓

SSL certificate terpasang dan valid. Koneksi aman untuk pengunjung.

✓ Sudah baik

3. Mobile-Friendly Perlu Perhatian

Teks terlalu kecil di layar mobile

Font size di bawah 12px pada beberapa bagian. Google menandai ini sebagai masalah mobile usability.

● Dampak sedang · Direkomendasikan

Galeri portofolio sulit dinavigasi di HP

Tombol dan elemen klik terlalu berdekatan. Pengguna mobile sering salah tap. Ukuran tap target minimal yang disarankan adalah 44×44px.

● Dampak sedang · Direkomendasikan

4. Konten & Konversi Perlu Perhatian

Tidak ada CTA (Call to Action) yang jelas

Pengunjung tidak diarahkan untuk menghubungi atau memesan jasa. Tidak ada tombol "Hubungi Saya" atau "Konsultasi Gratis" yang menonjol.

⚠ Dampak tinggi · Perbaiki segera

Shortcode WooCommerce tampil mentah

Halaman "My Account" menampilkan [woocommerce_my_account] sebagai teks biasa — tanda plugin tidak terkonfigurasi dengan benar.

● Dampak sedang · Bug teknis

Tidak ada testimonial atau social proof

Profil menampilkan pengalaman kerja, tetapi tidak ada ulasan klien, logo klien, atau proyek unggulan yang membangun kepercayaan.

● Dampak sedang · Direkomendasikan

Segera

Bulan ini
